## Overview

A custom reservation time picker built with Next.js 13 App Router. The component provides an intuitive interface for selecting reservation dates and available time slots.

## Features

- **Date selection** with date-fns for date manipulation
- **Time slot picking** with visual indicators for availability
- **Responsive design** built with Tailwind CSS
- **Clean UI** using lucide-react icons

## Tech Stack

- **Next.js 13** with App Router
- **React 18** with TypeScript
- **date-fns** for date manipulation and formatting
- **Tailwind CSS** for styling
- **lucide-react** for icons
